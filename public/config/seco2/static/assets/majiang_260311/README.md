# 麻将牌离线版

这是一个完全离线版的麻将牌游戏，无需任何服务器即可运行。

## 目录结构

```
majiang/
├── index.html          # 主页面文件
├── download_images.py  # 图片下载脚本
└── images/             # 麻将牌图片目录
    ├── 1m.png - 9m.png    # 万子牌
    ├── 1p.png - 9p.png    # 筒子牌
    ├── 1s.png - 9s.png    # 条子牌
    ├── dong.png, nan.png, xi.png, bei.png  # 风牌
    ├── zhong.png, fa.png, bai.png  # 三元牌
    └── mapping.json      # 图片映射文件
```

## 使用方法

1. 确保 `images` 目录中的所有图片已下载（运行 `python download_images.py`）
2. 直接在浏览器中打开 `index.html` 文件即可开始游戏

## 游戏规则

### 解锁机制
- 初始解锁：万、筒、条的 1-8 号牌
- 当某花色解开 6 张牌后，解锁该花色的第 9 张牌
- 当三个花色的第 9 张牌都解开后，解锁东南西北风牌
- 当四个风牌都解开后，解锁中发白三元牌

### 答题机制
- 每张牌有对应的答案（中文）
- 答错后需要等待 60 秒冷却时间
- 初始有 5 次尝试机会

### 提示系统
- 初始有 10 点提示点
- 可以用提示点直接兑换答案（不同牌消耗不同）
- 可以用 1 点提示点兑换 3 次尝试机会

### 进度保存
- 游戏进度自动保存在浏览器本地存储（localStorage）
- 点击"重置游戏进度"按钮可以清除存档

## 技术说明

- 纯 HTML/CSS/JavaScript 实现
- 使用 localStorage 保存游戏进度
- 图片资源本地化，无需联网
- 响应式设计，支持移动端

## 浏览器兼容性

- Chrome/Edge (推荐)
- Firefox
- Safari
